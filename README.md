# 🧠 Local RAG System with Role-Based Access Control (FGAC)

This project is a **fully local, production-style Retrieval-Augmented Generation (RAG) system** built using **only free and open-source tools**.

It allows employees to ask questions from **company PDFs (policies, SOPs, reports, etc.)** and receive **accurate answers generated by a local LLM**, while enforcing **role-based document access**.

No cloud. No paid APIs. No data leaves the system.

---

## 🚀 What This Project Does

- Converts company PDFs into searchable vector embeddings
- Stores them in a local vector database
- Answers user questions using a local LLM
- Enforces **fine-grained access control (FGAC)** so users see only allowed documents
- Provides a chat-style UI for interaction
- Logs user activity for audit purposes

## 🔄 End-to-End Working (Step-by-Step)

### 1️⃣ Environment Setup
- Created Python virtual environment
- Installed all required libraries

---

### 2️⃣ Local LLM (Ollama)
- Installed Ollama
- Pulled `llama3.1:8b`
- Ollama runs as a **local AI server** on:
http://localhost:11434


---

### 3️⃣ Vector Database (Qdrant)
- Qdrant runs locally via Docker:
http://localhost:6333


- Stores vectors + metadata
- Performs similarity search

---

### 4️⃣ User & Role Management
- SQLite database stores:
- user email
- role (HR / Finance / Ops / Manager)
- Enables role-based access control

---

### 5️⃣ Document Ingestion
- PDFs are read using PyPDF
- Each PDF page is treated as one chunk
- Chunks are converted to embeddings using sentence-transformers
- Stored in Qdrant with metadata:
- `allowed_role`
- `source`

---

### 6️⃣ RAG Query Flow
When a user asks a question:
1. Question is converted to a vector
2. Qdrant searches for similar vectors
3. Role-based filtering is applied **inside Qdrant**
4. Relevant chunks are retrieved
5. Chunks are sent to the local LLM
6. LLM generates an answer **only from provided context**

---

### 7️⃣ FastAPI Backend
- Exposes `/ask` endpoint
- Validates user via email
- Fetches role from SQLite
- Calls RAG logic
- Logs user activity
- Returns answer to client

---

### 8️⃣ Streamlit UI
- Simple chat interface
- Collects email + question
- Sends request to FastAPI
- Displays the response

---

## 🔐 Fine-Grained Access Control (FGAC)

- Access control is enforced at **vector search level**
- Users never see unauthorized documents
- Filtering happens **before answer generation**
- UI cannot bypass backend or database rules

## 🚀 How to Run the Application

```bash
# 1️⃣ Start Qdrant (Vector Database)
docker run -d -p 6333:6333 qdrant/qdrant

# 2️⃣ Start Ollama (Local LLM)
ollama run llama3.1:8b

# 3️⃣ Ingest Documents
python backend/ingest.py

# 4️⃣ Run Backend API (FastAPI)
uvicorn backend.main:app --reload

# 5️⃣ Run Streamlit UI
streamlit run ui/app.py
```
